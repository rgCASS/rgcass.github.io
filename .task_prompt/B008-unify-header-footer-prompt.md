【核心目标】 
统一研究小组官网所有页面（首页+四个专题页）的页眉导航栏和页脚，确保全站样式一致，用户体验统一。

【技术约束】 
1. 核心依赖/框架：原生 HTML + CSS + JavaScript，复用现有项目的样式体系和 CSS 变量配色；
2. 运行环境：现代浏览器（Chrome/Firefox/Edge/Safari），支持桌面端和移动端；
3. 其他要求：只统一页眉页脚，不改动页面主体内容；保持现有响应式适配正常工作。

【需求描述】
**业务背景**：目前四个研究方向专题页（认知解码、PsyMem、Casevo、认知塑造）已经完成内容开发，但各个页面的导航栏和页脚样式不统一，缺乏一致的用户体验。需要为所有页面统一添加一致的导航栏和版权声明页脚，确保网站整体风格统一。

**功能说明**：
- 为所有页面（index.html、cognitive-decoding.html、psymem.html、casevo.html、cognitive-shaping.html）统一导航栏
- 导航栏样式与首页保持一致，确保响应式适配移动端
- 为所有页面底部添加统一版权声明页脚
- 调整各个页面的内容区域 padding/margin，避免内容被导航栏遮挡
- 当前页面的导航链接需要高亮显示

**用户场景**：访客在浏览不同专题页面时，能够通过导航栏快速切换到其他页面，底部能看到统一的版权信息，提升网站专业性。

【功能细节】 
1. 【必填】核心逻辑： 
   - **统一导航栏规范**：
     - 在所有页面顶部添加固定导航栏，结构：左侧显示小组名称 "rgCASS"，右侧显示导航链接；
     - 导航链接顺序：网站首页 | 研究方向 | 业务合作 | 团队构成 | 联系我们；
     - **链接规则**：
       - 在专题页（非首页）中，所有导航链接指向 `index.html` 对应锚点（如 `index.html#hero`、`index.html#research`）；
       - 在首页中，导航链接直接使用锚点（如 `#hero`、`#research`）；
     - 当前页面所在位置导航链接需要高亮（使用现有下划线高亮样式）；
     - 导航栏样式与首页保持完全一致（毛玻璃背景、模糊效果、悬停下划线动画）；
     - 移动端保持可折叠汉堡菜单，交互逻辑与首页一致。
   - **统一页脚规范**：
     - 在所有页面底部添加统一版权声明页脚；
     - 版权信息内容：`© 2025-2026 智能体与社会仿真实验室. All Rights Reserved.`；
     - 样式与首页页脚保持一致（背景、边框、间距）。
   - **适配调整**：
     - 调整各个页面的内容区域 padding-top，确保第一屏不被固定导航栏遮挡；
     - 检查并确保移动端导航栏不溢出、不遮挡内容；
     - 保持所有现有 JavaScript 功能正常（移动菜单开合、粒子动画等）。

2. 输入/输出：修改现有 HTML 文件，输出统一后的全站页面；
3. 边界场景：确保移动端缩放正常，无横向滚动条；无 JavaScript 控制台错误。
